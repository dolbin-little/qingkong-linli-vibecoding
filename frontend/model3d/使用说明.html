晴空邻里 · 三维产品模型使用说明

版本 2.0 精细版 · 2026-10-23。包含太阳能辅助无人机、光伏共享站点、社区配送场景三类真实网格模型。所有依赖均随项目保存，使用时不需要访问 CDN。

本次升级：精细模型与产品图册

新增倒角外罩、曲面桨叶、电机绕组、紧固件、飞控与功率 PCB、电芯、线束、柜内共享物品及充电触点。模型页面增加“整机 / 爆炸分解 / 内部透视”快捷模式，支持开关外壳透视。附带 Blender 可编辑工程和六张产品结构、原理与协同设计图。点击打开产品设计图册，图册可直接以本地文件方式浏览，不依赖后端服务。

2026-10-23 已修复旧 BAT 的 LF 换行导致 Windows CMD 截断命令的问题：启动文件现为 ASCII + CRLF，并委托独立 PowerShell 入口。已实际以 CMD 执行验证，而不只是检查网页文件。

一、打开方式

双击项目根目录的 打开三维产品展示.bat。它先启动或复用原平台，再打开三维页面。也可从原平台左侧“产品与硬件 → 三维产品展示”进入。地址：http://127.0.0.1:8765/assets/model3d/index.html。请用 Edge / Chrome 并启用硬件加速，不要直接双击 HTML 文件。

如果暂时没登录，模型会自动使用独立演示；登录原平台后，在社区场景点击“连接平台数据”。演示不要求连接无人机。关闭后台服务时使用项目原有 stop.ps1，不要随意结束电脑上的其他 Python 进程。

三、模型参数和结构

模型设计表达对应软件参数
无人机四旋翼 X 形；轴心间距 0.78 m；桨半径 0.15 m；中部光伏板 0.40 × 0.30 m；电池、飞控、底挂载荷、双侧起落架。机载光伏 0.12 m²；电池 180 Wh；载重上限 1.8 kg；返航安全余量 20%。
站点基座约 3.5 × 3.65 m；后方物品柜与光伏棚，前方两座停靠台；侧面边缘控制和储能柜。光伏 3 m²；储能上限 1000 Wh；2 个充电位；单口 100 W，效率 92%。
社区1000 × 700 m；4 站点、6 公共取件点、3 默认禁飞区；建筑体块与道路沿用二维地图布局。平台 (x,y) 转为三维 (x−500,高度,y−350)。航线由原算法返回的路径点构成，无人机读平台位置。

硬件尺寸为概念设计值；电池、载荷、转换效率及充电参数为平台假设，尚未经样机实测。机载太阳能只作辅助补能：720 W/m² 时估算 720 × 0.12 × 0.20 × 0.90 ≈ 15.55 W，明显低于平台飞行功率假设，不能据此宣称太阳能独立驱动或无限续航。

四、技术架构

原平台保留 FastAPI / Uvicorn 后端、SQLite 状态存储和原生 HTML / JavaScript 前端。三维层新增 Three.js 0.180.0（MIT），使用 WebGLRenderer、OrbitControls、Raycaster 与命名部件网格，原生 ES Modules 加载；不需要 Vue、React、云服务或付费插件。

社区模型读取 GET /api/state；权限和变更继续由原后端控制。VNS 负责全局任务分配，HiGHS MILP 检查局部路径、时间窗、载重与返航电量，可视路径图绕开矩形禁飞区；三维层直接展示结果，不替换优化器。能源仍由原 LSTM 预测及 MPC–MILP 处理，三维页面只读取状态，不新增气动或充电求解模型。现有 DQN、MQTT 等模块未因本次建模改变。

独立示例由 tools/build_model3d.py 调用原平台 seed_state 与 apply_dispatch 生成；不会访问 SQLite。demo-state.json 保存实际求解结果；回放只对路径做插值，不将回放视作实飞验证。

五、交付文件与后续编辑

frontend/model3d/models.mjs 是可编辑的参数化建模源文件，修改尺寸后刷新页面；viewer.mjs 为交互和接口代码，viewer.css 为页面样式；downloads/ 包含 3 套 GLB / OBJ / STL。GLB 可在 Blender 中“文件 → 导入 → glTF 2.0”打开，部件保留独立层级。导出脚本 tools/export_model3d.mjs 可用 Node.js 重新生成模型。随附离线展示包可解压后运行启动脚本，无需安装原平台；需要 Python 3，启动脚本优先复用本项目已有 Python。

六、展示边界

社区站点放大 5 倍、无人机放大 16 倍，用于远景辨识；标记不是严格比例测绘。飞行高度统一按 40 m 展示，不表示可用空域或真实航高。当前版本不模拟三维避障、碰撞、真实气动、太阳入射角、自动着陆、电子电路或飞控指令。模型不是可直接生产的工程图或适航证明；打印网格也需进行制造检查。

本页用于解释软件和硬件概念成果，不将导师论文或专利直接宣称为学生独立研发的硬件实物。需要正式硬件参赛时，可将模型、交互演示和软件代码作为设计证据，样机测试记录应按实际完成情况提供。
