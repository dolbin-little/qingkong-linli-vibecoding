## 复核顺序

1. 用 [项目 README](../README.md) 和 [启动验收记录](validation/clean-start-verification.json) 复现一笔正常模拟配送。
2. 选择上表的一条 AI 迭代，读原始对话，再运行 `git show 82f2ec6` 等对应命令检查改动。
3. 对照验收结果观察订单、库存和运力的变化。固定评测的普通及风扰场景完成 12 次，动态障碍 6 次均触发保护停止。业务全流程由自建模拟器验证，官方 SITL 的独立验证范围见其验收记录。
