## 10分钟启动

推荐使用随附运行依赖的完整 ZIP，Windows 10/11 64位，建议8GB内存，使用支持WebGL的 Edge/Chrome。完整解压到有写权限的目录，勿在压缩包内启动。基础演示无需安装 Python、Node.js、飞控或连接真实无人机。

1. 完整解压“晴空邻里_软件创新版_完整运行包”到任意有写权限的位置。
2. 若本机已运行其他副本，先在那个副本中执行“停止本项目服务.cmd”，确保19051、19052及UDP18751空闲。
3. 双击“启动网页平台.cmd”。浏览器打开 `http://127.0.0.1:19051/`。管理员 `admin`，演示密码 `GreenFlight2026!`。
4. 需要桌面软件时，双击“启动独立飞行软件.cmd”；“启动全部.cmd”可以同时打开两端。
5. 网页进入飞行任务舱：连接模拟飞控 → 获取操控权 → 选择一个待调度订单 → 预检订单方案 → 载入任务 → 等待遥测刷新 → 飞前解锁 → 开始执行。
6. 观察爬升、巡航、交付点着陆停桨、模拟卸货反馈、重新起飞、返航落地。不同站点与航线通常需要1至3分钟。
7. 查看订单状态、库存与机队状态；进入“安全与接管”查看保护提示，进入“测试评价与回放”查看已保存图文评测。

没有待调度订单时，在订单管理中新建“雨伞、1件、六个已配置公共取件点之一”的配送订单。地图任意自选点尚未配置局部着陆场映射时不能直接用于这套飞行联调。

停止：先确认飞机已落地、未解锁，再运行“停止本项目服务.cmd”。该脚本仅处理当前目录记录且可执行路径匹配的进程。

## 源码部署与依赖

源码依赖声明在 `requirements.txt`，锁定清单在 `requirements-lock.txt`。完整包内 `runtime/python` 已包含实际运行环境；工作目录的runtime与Three.js可能是目录联接，打包后均为实际文件。只克隆Git仓库不会自动得到这些大型依赖。

自行部署使用Python 3.12、Tkinter以及对应平台依赖，依据锁定清单安装；Three.js等静态资源需按 `docs/第三方资源说明.txt` 和项目现有vendor路径提供。推荐评审使用完整包，避免首次依赖安装与下载的不确定耗时。官方SITL依赖来源、许可与SHA256记录在 `third_party/ardupilot_sitl/manifest.json`、`SOURCE.txt`，恢复命令为 `runtime/python/python.exe tools/install_sitl.py`。

配置：`config/project.json`。本地端口19051（网页）、19052（独立飞行服务）、UDP18751（自建模拟飞控）。实际代码中的地址与配置需一致；当前不是通过改一个端口字段就能自动迁移全部服务。

环境变量模板见 `.env.example`。程序不自动加载.env；按PowerShell命令显式设置。启动脚本会将GREENFLIGHT_DB设为本副本data/community.db。默认密码只适合本地演示；已有账号不会因更改环境变量自动重设。

## 架构与代码入口

网页 HTML/CSS/JavaScript/Three.js → FastAPI业务后端与SQLite台账；网页、Tkinter桌面均连接独立Python飞行服务；飞行服务通过pymavlink与模拟飞控通信。外环目标20Hz，飞控负责姿态和电机内环。

- `backend/flight_orders.py`：预检、库存及运力预占、订单回写、取消与核对恢复。
- `autonomy/engine.py`：任务状态机、控制与安全调度。
- `autonomy/planning.py`：2.5D A*、航点简化、逐段净空检查。
- `autonomy/perception.py`、`autonomy/models.py`：目标跟踪与运动控制相关模型。
- `autonomy/safety.py`、`autonomy/safety_status.py`：保护判断、解释与周期统计。
- `autonomy/mavlink_adapter.py`：遥测、命令回执与飞控协议。
- `desktop/console.py`、`frontend/sky.*`：桌面与网页交互。
- `tools/benchmark.py`、`tools/sitl_acceptance.py`：固定场景与官方飞控验收。

## 常见问题

- **端口占用**：先停止已运行副本；不要结束其他无关Python进程。查看logs中的服务日志。
- **载入场景没反应**：确认连接、已获取操控权、飞机在地面且未解锁；查看操作结果及安全提示。
- **订单不能执行**：查看预检的库存、载荷、电量、航线及公共取件点映射说明。
- **另一端持有操控权**：从该端释放或等待租约过期，再获取，避免两端同时控制。
- **卸货失败或重启后资源被占用**：先核对飞机与货物，再使用人工恢复，不能直接把库存改回去。
- **三维空白**：启用浏览器硬件加速或使用俯视视图；检查vendor资源是否完整。
- **干净解压后仍无法启动**：确认未只复制源码，且runtime/python/python.exe存在；日志路径为logs/。
